# Mathematical Function and Data Visualization using NumPy and Matplotlib

## Short Project Description
This project demonstrates the use of Python libraries such as NumPy and Matplotlib for mathematical visualization and data analysis. The notebook contains multiple visualization tasks including plotting mathematical functions, drawing a parametric heart curve, analyzing student score distributions, and generating a regression best-fit line. The project highlights how graphical representations make mathematical concepts and datasets easier to understand.

---

# Libraries Used

- NumPy  
  Used for numerical operations, array creation, mathematical computations, and generating data points.

- Matplotlib  
  Used for creating plots, graphs, histograms, scatter plots, and visualizations.

- Python built-in `math` library  
  Used for additional mathematical operations.

---

# How to Run the Code

## Requirements

Install the required libraries using:

```bash
pip install numpy matplotlib notebook
```

## Running the Notebook

1. Download the project notebook:
   - `math_visualization.ipynb`

2. Open a terminal in the project directory.

3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

4. Open `math_visualization.ipynb`.

5. Run the cells sequentially to generate all visualizations.

# Short Explanation

## How does visualization help us understand mathematical functions and data?

Visualization converts numerical and mathematical information into graphical form, making patterns, trends, and relationships easier to interpret. Graphs help identify behaviors such as growth, oscillation, distribution, and correlation that may not be obvious from raw equations or datasets alone.

---

## Which plot was most useful in this assignment and why?

The regression best-fit line plot was the most useful because it clearly showed the relationship between midterm and final exam scores. It helped visualize the correlation between the two datasets and demonstrated how statistical analysis can be represented graphically.

## What is the role of NumPy and Matplotlib in your project?

### NumPy
NumPy was used to generate arrays of values, perform mathematical computations, and efficiently handle numerical data.

### Matplotlib
Matplotlib was used to create all visualizations including line graphs, scatter plots, histograms, bar charts, and regression plots.
